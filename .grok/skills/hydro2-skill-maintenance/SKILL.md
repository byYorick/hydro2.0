# Поддержка проектных skills Hydro 2.0

## Определи задачу

Из запроса и контекста выдели конкретный сценарий, условия активации и результат. Не создавай skill только по совпадению ключевого слова; обнови существующий, если он уже покрывает задачу.
Прочитай [проектный каталог](../../../doc_ai/10_AI_DEV_GUIDES/PROJECT_SKILLS.md) и AGENTS.md. Skills не создают новую канонику архитектуры и не расширяют разрешённую автономию агента.

## Адаптируй источник

Исследуй первичный публичный репозиторий; зафиксируй URL файла, commit, blob SHA и лицензию в tools/skills/project-skills.json. Сохрани требуемые license/notice. Не запускай скачанные скрипты только для ознакомления.
Перепиши workflow под Hydro: Docker для backend, Laravel-миграции, commands только через HL, отдельные realhw/test DB, запрет новых task_type/сервисов без запроса. Внешние правила auto-ship, публикации и делегации не наследуются автоматически.

## Структура

- SKILL.md: name совпадает с каталогом, description задаёт действие и ситуации применения. Технические type/lifecycle/version находятся в metadata, а не в произвольных корневых YAML-полях.
- Тело содержит короткий рабочий процесс, границы и ссылки на 2–3 канонических документа. Подробные SQL/справки вынеси в references.
- CHANGELOG.md фиксирует изменение; evals/evals.json содержит реалистичные prompts, ожидаемые результаты и проверяемые expectations. Отрицательный trigger-case можно пометить should_trigger=false.
- Одна версия тела хранится в canonical path манифеста; discovery-пути используют относительные symlinks внутри репозитория. Не делай копии, которые будут расходиться.

## Проверь

```bash
make skills-install
make skills-check
git diff --check
```

Локальная проверка подтверждает структуру, aliases, provenance и сценарии. Она не исполняет prompts и не измеряет качество модели. Для модельной оценки отдельно выбери примеры, зафиксируй baseline/with-skill результаты и реально выполненные проверки; не выдумывай pass rate.
Независимые агенты, внешняя публикация и платные запуски используются только в разрешённых пользователем/средой пределах. Отсутствие модельного benchmark не мешает честно завершить поставку локальных файлов и структурной проверки.

## Результат

Назови новые/обновлённые skills, первичные источники и изменения для Hydro. Дай фактические результаты проверок и ограничения. Не переписывай legacy skills-lock.json хешами собственной адаптации.
