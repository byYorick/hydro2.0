# Архитектурные решения (ADR)

**Версия:** 0.1
**Дата:** 2026-11-09
**Статус:** `guide` каталога. Сами решения — `proposed`, пока владелец не сменит статус.

Каталог сквозных архитектурных решений Hydro 2.0. ADR не является защищённым
контрактом и не описывает текущий runtime. Поведение кода — по-прежнему код.
Пока статус `proposed`, спецификации слоёв `01`–`08` не переписываются этим
каталогом.

Отдельного типа документа в репозитории не было. Каталог лежит в `doc_ai/adr/`,
а не внутри одного слоя: решения пересекают Laravel, AE3, MQTT, схему БД,
фронт и прошивку. Это не новая версия архитектуры (`v3`/`v4` не заводятся).

Сверено с `main` @ `ba461dce` (2026-11-09). План масштаба, на который опираются
решения: [PR #32](https://github.com/byYorick/hydro2.0/pull/32), файл
`doc_ai/01_SYSTEM/SCALING_PLAN_400M2_MODULES.md` в ветке
`feature/docs-scaling-plan-400m2`. В `main` этого файла ещё нет.

## Нумерация и статусы

Имена файлов: `ADR-NNNN-краткое-имя.md`, номера с `ADR-0001`, без пропусков.
Номер не переиспользуется.

| Статус | Смысл |
|---|---|
| `proposed` | решение записано, в код и в канон контрактов не перенесено |
| `accepted` | владелец принял; реализация — отдельными PR, контракты слоя обновляются там |
| `rejected` | не делаем; файл остаётся |
| `superseded` | заменено другим ADR; в шапке ссылка на замену |

Внутри текста метки **live** / **planned** / **frozen** значат то же, что в
[IMPLEMENTATION_STATUS.md](../IMPLEMENTATION_STATUS.md): что есть в runtime,
что только намерение, что не расширять без запроса.

## Шаблон

```markdown
# ADR-NNNN. Название

**Версия:** 0.1
**Дата:** YYYY-MM-DD
**Статус:** `proposed`
**Метки:** факты текущего кода — **live**; целевое поведение — **planned**.

Compatible-With: Protocol 2.0, Backend >=3.0, Python >=3.0, Database >=3.0, Frontend >=3.0.

## Связанные документы

## Контекст

## Решение

## Альтернативы

## Последствия

## Задачи

## Критерии приёмки
```

Разделы не выкидывать. В «Контексте» — файлы и строки текущего кода.
В «Задачах» — исполнитель (Hydro2 Бэк, Hydro2 Автоматика, Hydro2 Фронт,
Hydro2 БД, прошивка). Критерии приёмки проверяемые, без отсылки «сделать хорошо».
