# Программа выращивания: первая теплица и модули

**Статус:** `plan`  
**Дата:** 2026-11-01  
**Снято с кода:** `main` @ `ff796c3c` (находки аудита). Исправления SEC/SAF лежат в открытых PR и в `main` ещё не влиты.  
**Аудитория:** владелец и разработчики hydro 2.0

Это план продукта, а не канон runtime. Поведение системы по-прежнему определяется кодом. Защищённые контракты MQTT, команд, схемы БД и AE3 остаются в своих разделах `doc_ai/`. Очередь агента на суточный контур (`04_BACKEND_CORE/AE3_CROP_DAY_LOOP_PLAN_FOR_AI_AGENTS.md`, версия 1.2.0) этим разделом не подменяется и не отменяется.

Площадка: Крым, теплица сезонная (не круглогодичная). Культуры первого контура: листовая зелень и клубника нейтрального дня. Первая система полива: капля на субстрате. Масштаб: 20 м², затем модуль 400 м².
