# Справочники выращивания

**Статус:** `guide`. Материалы для выбора агрономических параметров и оборудования.

- [AGRONOMY_CRIMEA.md](AGRONOMY_CRIMEA.md) — сезонная теплица, зелень и клубника; ориентиры не заменяют анализ воды, сортовые данные и опубликованную ревизию рецепта.
- [HARDWARE_BOM.md](HARDWARE_BOM.md) — состав оборудования и ориентировочная стоимость; не подтверждение наличия/приёмки стенда и не закупочное поручение.

Рабочие цели контроллеров берутся из активной фазы цикла и compiled automation
bundle по [EFFECTIVE_TARGETS_SPEC.md](../06_DOMAIN_ZONES_RECIPES/EFFECTIVE_TARGETS_SPEC.md).
Текущий суточный контур описан в [CROP_DAY_RUNTIME.md](../04_BACKEND_CORE/CROP_DAY_RUNTIME.md).
Исторические снимки состояния, gap-анализ и дорожная карта в этот справочник не входят.
